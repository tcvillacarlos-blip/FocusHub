# FocusHub – Student Productivity Website

**Student:** Ahron Joshua Villacarlos  
**Category:** Education / Student Productivity

## Project description
FocusHub is a responsive student productivity website that helps students organize school tasks, find study resources, view upcoming activities, and manage a simple profile.

## Main pages
1. Home – project introduction and task progress
2. Planner – add, complete, and delete tasks
3. Resources – search and filter study resources
4. Events – view upcoming activities
5. Profile – save student information

## Technologies used
- HTML5
- CSS3
- JavaScript
- Local Storage
- Responsive design

## Interactive features
- Responsive mobile navigation
- Dark/light mode
- Task form validation
- Add/complete/delete tasks
- Local Storage for tasks and profile
- Search and category filtering for resources
- External resource links

## How to run
Open the project folder in Visual Studio Code. Install the **Live Server** extension, right-click `index.html`, then select **Open with Live Server**.
